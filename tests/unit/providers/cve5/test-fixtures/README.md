# CVE 5 test fixtures

Records are copied unmodified from https://github.com/CVEProject/cvelistV5 (`cves/<year>/<bucket>/CVE-*.json`). `CVE-2023-2004.json` is a `REJECTED` record. `deltaLog.json` is a copy of cvelistV5's `cves/delta.json`, which stands in for the (much larger) `deltaLog.json`: the provider ignores both by name.
